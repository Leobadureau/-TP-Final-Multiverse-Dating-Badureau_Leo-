## Fonctionnalités

- **Affichage des personnages** : cartes interactives avec photo, nom, statut et espèce.
- **Swipe** : 
  - Like → ajoute le personnage à vos crushs.
  - Pass → passe au personnage suivant.
- **Filtres** : par nom, statut (alive, dead, unknown) et espèce (Human, Alien, Robot, Unknown).
- **Compteurs** : suivi du nombre de likes et de passes.
- **Liste de crushs** : affichage dynamique des personnages likés.
- **Mode jour/nuit** : bascule entre thème sombre et clair.
- **Responsive** : s’adapte aux écrans de bureau et mobiles.

## Structure des fichiers

├─ index.html # Structure HTML principale
├─ style.css # Styles et thème dark/light
├─ script.js # Logique JS : fetch API, swipe, filtres, compteurs
└─ README.md # Documentation du projet

## API utilisée

Rick and Morty API : https://rickandmortyapi.com/api/character
Récupération dynamique des personnages et leurs informations.
